How to interpret this forecast

Deterministic models: ECMWF, GFS, ICON and UKMO produce distinct model predictions. Agreement among them does not imply independent evidence or a calibrated likelihood.

True ensembles: Variations of a model predict different plausible outcomes. We show member percentiles and threshold exceedance fractions for the selected ensemble; these are indicative, not statistically calibrated probabilities.

Observations: Radar gives recent remotely sensed precipitation imagery. Verified on-the-ground weather station data is not yet available in v0.1.

Freshness: Each data request timestamp records when the app retrieved the data. It is not the weather model run issue time.
